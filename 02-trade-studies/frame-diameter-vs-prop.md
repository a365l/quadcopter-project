# Trade Study: Frame Diameter vs Propeller Size

## Options Considered

| Data Point | 13" Props @ ~600mm frame | 15" Props @ ~700mm frame |
|---|---|---|
| Prop diameter | 13 in (0.330 m) | 15 in (0.381 m) |
| Swept area (per rotor) | 856.34 cm² | 1140.09 cm² |
| Total thrust required (3.5 kg hover) | 34.3 N | 34.3 N |
| Thrust per rotor | 8.58 N | 8.58 N |
| Disc loading | ~100.1 N/m² | ~75.2 N/m² |
| DL vs typical multirotor (~140–290 N/m²) | Below typical range | Well below typical range |
| DL vs DJI M30 anchor (~71.2 N/m²) | Above anchor, same order | Close to anchor |
| Motor-to-motor spacing (frame/√2) | ~424.26 mm | ~494.97 mm |
| Rotor inertia / spool-up responsiveness | Lower inertia - faster response | Higher inertia - slower response |
| Arm resonance margin | Unresolved - pending Phase 1 calc | Unresolved - pending Phase 1 calc |
